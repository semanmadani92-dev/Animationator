# "What if" style samples

The same character and scene ("What if gravity turned off for 5 seconds?") in three styles:
`style_flat.png`, `style_doodle.png`, `style_comic.png`.

Drawn as SVG in `src/` (`art.js` holds the character and props, `scene.html?s=flat|doodle|comic` the scenes).
Render with `node src/shoot.js <out_dir>` (Playwright). Fonts (Google Fonts, OFL): put LilitaOne-Regular.ttf,
PatrickHand-Regular.ttf and Bangers-Regular.ttf in `src/fonts/`.
